# 視界致富羅盤（線上版）

視界學院財商教學遊戲，進度存在瀏覽器本機。需輸入密碼進入。

## 網址一覽

| 網址 | 內容 | 用途 |
|---|---|---|
| `/` | **正式版**（v4.3） | 上課用。副控台驗收通過前不會被更動 |
| `/v4/` | **凍結快照＝v4.3** | 保命連結。**永遠不要修改或刪除這個目錄**；正式版日後升級了，這裡仍是講師熟悉的版本 |
| `/beta/` | 副控台版主控（開發中） | 只供彩排測試，畫面左下角有 BETA 標記 |
| `/beta/console/` | **組長銀行台**（開發中） | 每桌志工用的平板畫面，不需要密碼 |

`/beta/` 與正式版使用**不同的 localStorage 存檔鍵**（`zfl-compass-v6b` vs `zfl-compass-v5`），
組長銀行台又是另一把（`zfl-console-v1`），三邊互不覆蓋。

### 組長銀行台怎麼用（彩排階段）

1. 講師在 `/beta/` 連點左上角 Logo 三下 → 按「開啟連線」（房號 `VISION`）。
2. 組長用自己的平板開 `/beta/console/` → 輸入同一個房號 → 選桌號、人數 → 開始。
3. 畫面會自動跟著講師走，一次只顯示一個指令；記帳存在組長自己的裝置上。

同步走兩條線，**兩條同時送、任一條掛掉另一條照常**：

- **網路**（Supabase Realtime）→ 志工用自己的平板時走這條。實測延遲中位數 58ms。
- **同一台電腦跨分頁**（瀏覽器內建 BroadcastChannel）→ 免網路。
  教室網路全掛時，這條仍然會動，等於自動退回原本的做法。

連不上時副控台上方會出現紅色橫幅，**帳本照樣可以記**；真的一直連不上就切「手動模式」自己選月份。

> **同時段有兩班在上課**才需要換房號：主持人面板 →「換房號」，換完通知各桌組長重新輸入。

> **上課前一天建議先開一次 `/beta/`＋`/beta/console/` 確認連得上。**
> 用的是免費 Supabase 專案，閒置太久會被自動暫停（已加每日 keepalive 排程，但不保證）。
> 萬一連不上：到 Supabase 後台按 Restore（約 1–2 分鐘），或當天改用「同一台電腦跨分頁」照樣能上課。
